# ROSES 2020 (AGU Seismology): free online course

11 lectures by working seismologists, each with a Python lab. Course page:
https://connect.agu.org/seismology/roses/roses2020materials

- **Labs** (Jupyter notebooks, 330 MB): https://github.com/fdannemanndugick/roses2020
  Not stored in this repo; get them with `git clone https://github.com/fdannemanndugick/roses2020 course/roses2020/labs`
- **Transcripts**: run `python course/roses2020/transcribe.py` on your own computer
  (`pip install yt-dlp faster-whisper` first). YouTube blocks cloud servers, so this can't run in the cloud.

Most useful for V1: Unit 3 (time series), Unit 4 (cross-correlation), Unit 5 (arrays, which is what a DAS cable is),
Unit 7 (machine learning on seismic data), Units 9–11 (inversion).
